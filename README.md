# Espaces Verts 64

Page d'accueil du site — paysagiste très haut de gamme, Pyrénées-Atlantiques.

Site statique, sans dépendance ni étape de build : ouvrir `index.html` ou servir le dossier
(`python3 -m http.server`).

- `index.html` — contenu
- `assets/css/style.css` — palette, typographie, mise en page
- `assets/js/main.js` — plans dessinés au trait (SVG généré) et apparitions au défilement
- `assets/fonts/` — Bodoni Moda et Jost, auto-hébergées (licence SIL OFL)

## À compléter

- Coordonnées réelles (courriel, téléphone) dans la section contact de `index.html`
- Nom définitif de l'entreprise (actuellement « Espaces Verts 64 »)
- Photographies des réalisations : remplacer chaque `<svg data-plate>` par une balise `<img>`
